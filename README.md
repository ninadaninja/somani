# 🌸 Somani

**Turn real-world Japanese into a personalized learning adventure.**

Somani is an AI-powered Japanese learning application that helps learners study authentic text from their everyday surroundings. Users can upload a photo of Japanese text—such as a menu, sign, article, or document—and Somani extracts the content, identifies vocabulary by JLPT level, and transforms selected words into an interactive conversation.

## ✨ Key Features

* 📷 Extracts Japanese text from uploaded images using AI-powered OCR
* 🎨 Highlights vocabulary according to JLPT level, from N5 to N1
* 📖 Allows users to save unfamiliar words to a personal vocabulary list
* 💬 Generates contextual conversations using the user’s selected vocabulary
* 🧑‍🎤 Features AI characters with unique personalities and scenarios
* 🔊 Provides audio playback for Japanese messages
* 📊 Tracks vocabulary usage and learning progress
* 🧠 Uses retrieval-augmented generation (RAG) to produce relevant learning experiences

## 💡 Why We Built It

Japanese learners often encounter useful vocabulary outside traditional textbooks but lack an engaging way to review it. Somani bridges that gap by turning real-world Japanese into personalized, interactive practice.
